# 50 Arms Claude Code marketplace

```
claude plugin marketplace add 50arms/claude-marketplace
claude plugin install danxbot@50arms
```

Then, in the repo you want to connect, run `/danxbot:start` inside Claude Code.

This repository is generated: it holds the catalog (`.claude-plugin/marketplace.json`) and the `danxbot/` plugin, copied from the plugin's source repo at each release. Do not edit it by hand.
